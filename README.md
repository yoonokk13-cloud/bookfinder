# 프로젝트: 우리도서관 책 찾기

## 목적
초등학생이 학교도서관 소장도서를 표지 중심으로 탐색하고, 읽기 전·중·후 
3단계 독후활동을 선택해 나만의 독서 활동지를 자동 생성·인쇄하는 교육용 웹앱.

## 주요 기능
- 책장 구경하기: 표지 카드가 랜덤 진열되는 face-out 탐색 화면, 주제별 필터
- 책 검색: 제목/저자/주제/서가/대출가능 여부로 검색
- 표지·소개 연동: 도서 API로 실제 표지·짧은 소개 표시, 못 찾은 책은 
  주제색+아이콘 대체 표지로 자동 전환
- 독서여정: 읽기 전/중/후 3단계 활동 카드(표지 탐정, 인상 깊은 문장, 
  4컷 만화 등) 선택 → 인쇄용 활동지 자동 생성(학생 이름/날짜 포함)
- 학생 개인정보 저장 없음(로그인 없음)

## 배포 방향 (단계적으로 접근)
**1단계 (지금, 급함): API 신청용 안정적인 URL 확보**
- 알라딘 TTB 등록, 국립중앙도서관 API 신청에 서비스 URL 필요
- GitHub Pages / Netlify / Vercel 등 무료 정적 호스팅으로 빠르게 확보

**2단계 (곧, 실사용 목표): 학교 실배포까지 염두에 둔 구조로 시작**
- ⚠️ 알라딘 등 API 키는 등록한 URL에 묶이는 경우가 많음 → 나중에 
  주소가 바뀌면 재등록해야 할 수 있으니, 처음부터 계속 쓸 고정 
  주소(예: 커스텀 도메인 또는 안정적인 프로젝트명)로 잡는 게 안전함
- 학급 단위(20~30명)가 동시에 써도 버틸 수 있어야 함 → 표지 이미지를 
  학생이 접속할 때마다 실시간으로 API 호출하는 대신, **빌드/배포 
  시점에 미리 한 번에 가져와 캐싱**하는 방식으로 전환 권장 
  (알라딘 일일 호출 제한 5,000건 보호 + 속도 개선)
- ✅ 사서교사가 개발자가 아니므로, 소장도서 목록 갱신(신간 추가 등)을 
  코드 수정 없이 반복할 수 있는 쉬운 절차 마련 → `update-books.html`로 해결
- HTTPS는 위 호스팅들이 기본 제공 → 별도 인증서 작업 불필요

## 특징
- 원본 소장도서 xlsx(전체 약 10,360권)를 청구기호(KDC) 기준 13개 
  주제로 자동 분류해 데이터화. **교사용서가 도서도 제외하지 않고 
  전체 포함**
- 알라딘 이용정책상 "도서 데이터 제공: 알라딘 인터넷서점" 출처 표기 필수
- 국립중앙도서관 Open API는 승인되는 대로 연동 예정

## 사용자
- 실사용자(운영자): 하랑초등학교 사서교사, 비개발자 → 배포·갱신 방법은 
  최대한 쉽고 구체적으로, 반복 가능한 절차로 안내 필요
- 최종사용자: 초등학생(저학년 포함) → 직관적 아이콘, 파스텔 톤, 쉬운 용어 유지

## 개발자
- Claude(챗)로 기획·설계·1차 제작(오프라인 프로토타입) 완료, 이후 
  웹 배포·API 연동·실사용 구조 전환은 Claude Code로 진행 예정

## 진행 현황
- ✅ 책 검색하기: 제목/ISBN 검색 → 표지·저자·출판사·줄거리 카드 (완료)
- ✅ 책장 구경하기: 실제 소장도서 xlsx(10,305권, 반출 불가 자료 제외) 기반
  face-out 카드 탐색 + 13개 주제 필터 + 표지 클릭 시 상세 정보(대출 상태,
  소장처, 청구기호 포함) (완료)
- ⏳ 독서여정(읽기 전/중/후 활동 → 활동지 자동 생성): 다음 단계에서 작업 예정

## 파일 구성
```
index.html              # 앱 전체(HTML+CSS+JS 단일 파일, GitHub Pages에 그대로 배포)
update-books.html        # 소장도서 xlsx -> books.json 변환 도구 (브라우저에서 실행, 비개발자용)
collection_source.xlsx  # 도서관에서 내려받은 원본 소장도서 목록
books.json               # 위 xlsx를 변환한 결과 (index.html이 읽음)
build_books.py           # xlsx -> books.json 변환 스크립트 (터미널용, update-books.html과 로직 동일)
```
(모든 파일이 저장소 최상위에 있어야 GitHub Pages와 상대경로 fetch가 정상 동작한다.)

## 소장도서 목록 갱신 방법 (신간 추가 등) — 비개발자용, 터미널 필요 없음
1. 배포된 사이트 주소 뒤에 `/update-books.html`을 붙여서 접속한다.
   (예: `https://yoonokk13-cloud.github.io/bookfinder/update-books.html`)
2. 도서관리 프로그램에서 새로 받은 소장도서 xlsx 파일을 화면에 끌어다 놓는다.
   (열 순서: No, 등록번호, 자료명, 저자, 출판사, 출판년도, 청구기호, 자료상태, 소장처, 가격, ISBN)
3. 화면에 뜨는 총 권수·주제별 권수가 맞는지 확인한다.
4. "books.json 다운로드" 버튼을 눌러 파일을 받는다.
5. 다운로드한 `books.json`과, 방금 넣은 xlsx 파일(`collection_source.xlsx`로 이름 변경)
   두 개를 GitHub 저장소에 업로드하고 커밋한다. (index.html 처음 올릴 때와 같은 방법)

터미널을 쓸 수 있는 사람이라면 `python3 build_books.py`(로컬에 `collection_source.xlsx`를
먼저 덮어쓴 뒤 실행)로도 똑같은 결과를 만들 수 있다. 두 방법은 완전히 같은 로직이라
결과 파일이 동일하다.

## 책장 구경하기 주제 분류 기준
청구기호(KDC 앞자리)와 소장처를 기준으로 13개 주제로 자동 분류한다.
- 그림책서가에 있는 책은 청구기호와 무관하게 "그림책"으로 분류
- 제목에 "도감"·"사전"이 들어간 책(총류 제외)은 "도감·사전"으로 분류
- 나머지는 KDC 0~9(총류~역사)를 백과사전/철학/종교/사회/자연과학/기술/
  예술체육/언어/문학/역사에 매칭
- 분류 기준은 `build_books.py`의 `classify()` 함수에서 조정 가능

## 알려진 제한사항 (2단계에서 개선 예정)
- 표지 이미지는 학생이 접속할 때마다 알라딘 API를 실시간 호출해서 가져옴
  → 동시 접속이 많아지면 알라딘 일일 호출 제한(5,000건)에 걸릴 수 있음
  → 빌드 시점에 표지를 미리 캐싱하는 방식으로 전환 필요
- TTBKey가 index.html 코드에 그대로 노출되어 있음 → 서버리스 함수로 이전 필요
- CORS 우회를 위해 공개 프록시(corsproxy.io 등)를 사용 중 → 안정성이
  완전히 보장되지 않으므로, 2단계에서 자체 프록시/서버리스 함수로 교체 권장
